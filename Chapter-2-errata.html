Algorithm ReachableWithPrePost (p. 32)
As printed visited[v] = marker
for all edges (v,u) ∈ E: if visited[u] = 0:
  parent[u] = v
  pre[u] = clock; clock++
  ReachableWithPrePost(G,u,marker)
post[v] = clock; clock++
Should be visited[v] = marker
pre[v] = clock; clock++
for all edges (v,u) ∈ E: if visited[u] = 0:
  parent[u] = v
  ReachableWithPrePost(G,u,marker)
post[v] = clock; clock++

As printed, pre is set only for nodes discovered from a parent, so the root of every DFS tree never gets a pre number. Another way to ensure that the roots get the pre number without changing ReachableWithPrePost is to add pre[v]=clock; clock++ within DFSWithPrePost just before making the call ReachableWithPrePost(G, v, i).
