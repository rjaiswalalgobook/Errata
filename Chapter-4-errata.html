(Major Issue)Paragraph before the running-time discussion
As printed“… the proof works irrespective of the order in which the events are assigned rooms. In other words, in whichever order the greedy strategy assigns events to rooms, the resulting assignment will be optimal.”
Should be“… the proof works whenever the events are considered in nondecreasing order of their start times (ties broken arbitrarily).”

The proof of Lemma 4.7 uses this order: it needs rooms 1, …, k−1 to be busy at the start time of the first event given room k. For an arbitrary order the lowest-available-room rule can use more rooms than necessary. For example, take A = 9:00–11:00, C = 13:00–15:00, B = 12:00–14:00, J = 10:00–12:30 in the order A, C, B, J. A and C get Room 1, B gets Room 2 (it overlaps C), and J overlaps A and B, so it gets Room 3, although no time has more than two events. The algorithm and analysis later in the section already use start-time order and are unaffected.

Related places: Figure 4.16, 4.17 gives 5 rooms (which is optimal) on this instance, but that is merely a coincidence of the instance.
